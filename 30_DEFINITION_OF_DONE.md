# 30 — Definition of Ready and Done

## Ready
A task is ready when user value, scope, priority, dependencies, testable acceptance criteria and permission/platform constraints are known.

## Done
1. Behaviour implemented and demonstrated.
2. Loading, empty, error and permission-denied states handled.
3. Architecture boundaries respected.
4. Relevant unit/widget/integration tests pass.
5. `dart format` and `flutter analyze` pass.
6. Android device verification performed for platform work.
7. Accessibility and touch targets reviewed.
8. No sensitive user content logged.
9. Docs, backlog and changelog updated.
10. Known limitations recorded.
11. Evidence linked in project status.

A milestone is Done only when all required tickets are Done and evidence is recorded.
