# 19 — Suggested Sprint Plan

A sample solo-developer sequence; adjust duration to available time.

| Sprint | Focus | Deliverable |
|---|---|---|
| 0 | Repo audit and setup | Reproducible Flutter/Kotlin build |
| 1 | Android HOME role | Selectable default launcher |
| 2 | Minimal home | Wallpaper + clock |
| 3 | Gestures | Right/left/up navigation |
| 4 | Native app discovery | Real installed app list |
| 5 | Drawer | Search, sort and launch |
| 6 | Settings/theme | Material You, fallback and persistence |
| 7 | Productivity | Notes and tasks |
| 8 | Widget spike | Native AppWidgetHost proof |
| 9 | Widget dashboard | Add, render, interact and remove |
| 10 | Spaces | Create and switch spaces |
| 11 | Organization | Groups and folders |
| 12 | Advanced | Focus, radial menu, usage insights if scoped |
| 13 | QA/release | Beta-ready build |

Sprint routine: select a small set of tickets; keep app runnable; demo on a device; run tests; update status and changelog. Never start an advanced feature while a P0 launcher flow is broken.
